    Fix: Comment opening <custom_item> tags for unused audit controls
    
    Root cause: The consolidation pipeline was not properly commenting opening
    tags when controls were marked as unused. The issue was in load_controls_catalog()
    which was looking for 'All_Occurrences' sheet instead of platform-specific sheets.
    
    Changes:
    - Added audit_type parameter to AuditConsolidator.__init__()
    - Updated load_controls_catalog() to load platform-specific sheets (PAFW, NXOS, etc)
    - Updated main() in consolidator script to pass audit_type
    
    Result: All opening <custom_item> tags are now properly commented for unused controls
    across all audit types (PAFW, NXOS, IOS, ASA, F5, RHEL, MSWRK, MSSRV, SQL)
